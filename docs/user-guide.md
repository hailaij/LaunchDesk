# LaunchDesk

[简体中文](../README.md) | [English](../README.en.md)

Windows 10/11 x64 启动项管理器。运行 LaunchDesk.exe；应用自带运行时，无需另外安装 .NET。

设置 → 外观 → 语言支持简体中文、English，保存后立即生效并保留选择。启动项名称、命令、路径和原始日志不翻译。

默认启动时在后台检查新版本，失败和已是最新版本不打扰，可在设置中关闭。发现新版本弹窗提供下载和发布页面入口；托盘状态下恢复窗口后再提示。下载必须由用户点击，不会静默安装。下载需通过 SHA-256、Windows Authenticode 及内置发行者证书固定验证；失败或取消时清理临时包，不替换旧程序和配置。当前尚未配置发行证书，应用内下载禁用，未签名安装包不会被接受。

隐私与联网说明：[隐私政策 / Privacy Policy](../PRIVACY.md)。

首次使用没有示例启动项。应用会读取当前用户的已有配置，因此升级后仍保留原启动项和日志。

每个启动项可设置资源、参数、工作目录、环境变量和编码。npm 命令必须选择包含 package.json 的正确工作目录。文件夹是应用内分组，不移动实际文件；删除文件夹保留启动项。

编辑窗口的“启动前检查”验证路径、解释器及简单 npm 脚本配置，不执行命令。真正启动前也执行检查；检查失败时不会启动依赖项。复杂 cmd 表达式只做基础路径检查。

可拖拽未运行的启动项调整顺序或加入文件夹，拖到列表空白处移出分组。文件夹可排序，不支持嵌套。拖入 BAT/CMD、EXE、PS1、SH 文件会打开编辑窗口确认，不移动原文件，也不自动启动。

“服务就绪检测”默认关闭。启用 TCP、HTTP 或日志关键词检测后，状态先显示“等待就绪”，成功后显示运行中，再启动依赖项。超时为 1–300 秒，失败时停止该项。日志关键词区分大小写，只检查本次运行；HTTP 需返回 2xx，不跟随重定向。TCP/HTTP 可命中已有服务，不能证明端点属于新进程，也不是持续健康监控。

窗口关闭会收起到托盘。托盘菜单的“退出”会停止受管进程。升级或卸载前请先退出旧实例。

双击名称可原位重命名，Enter 保存、Esc 取消，失去焦点保存；其他设置仍使用编辑按钮。启动项的“启动顺序”范围 0–9999，数字小的先启动，同值按列表顺序，依赖项优先于此顺序。此规则适用于全部启动、文件夹启动和登录自启，单独运行不自动启动其他无关项。

选中文件夹时显示组内各项的合并日志，按时间排列并注明来源。过滤、暂停、清空显示、导出和确认后删除历史均作用于整个文件夹。输入不会广播到文件夹内的进程，请选中具体启动项后发送输入。

日志中的 HTTP/HTTPS 链接高亮并带下划线，悬停显示地址，Ctrl+点击使用默认浏览器打开。普通点击不跳转，不自动访问链接；请只打开可信日志中的地址。

默认配置及日志目录为 %LOCALAPPDATA%\LaunchDesk。卸载不会删除这些用户数据。便携模式使用程序旁的 portable.flag 和 data 目录。

日志面板支持过滤、清空、导出及输入。清空显示不删除历史日志；删除历史需单独确认。

设置中的“数据与备份”显示当前实际目录，提供打开数据目录、打开备份目录及立即备份入口。手动备份在 backups\manual 中，不参与最近 20 份自动备份清理；只包含配置，不包含日志或脚本。恢复时使用主窗口配置导入，并先停止所有启动项。

可输入或选择新的空数据目录。切换前停止全部项；保存时复制配置、日志和备份，成功后立即切换并保留旧目录。便携模式使用程序旁的 data，不允许改为其他路径；要使用自定义目录，请取消便携模式。非空目录和符号链接不能作为迁移目标。用户模式的目录记录位于 %LOCALAPPDATA%\LaunchDesk-location.json，便携标记优先；卸载仍保留用户数据与目录记录。

项目及问题反馈：https://github.com/hailaij/LaunchDesk

设置中的“关于 LaunchDesk”提供版本、许可证和手动“检查更新”，可随时再次查询 GitHub 正式发布版本。新版本提示可以查看说明、打开发布页面；证书配置完成后可点击下载并验证安装包。不自动安装、退出应用或停止服务。
