# LaunchDesk

[简体中文](../README.md) | [English](../README.en.md)

Windows 10/11 x64 启动项管理器。运行 LaunchDesk.exe；应用自带运行时，无需另外安装 .NET。

v0.8.0：启动项可按次请求 UAC；设置中可独立安装、配置和控制 LocalService 后台服务（仅后台脚本/控制台程序）。服务使用独立数据，桌面升级不会自动升级服务。图标按钮提供读屏名称，F2 原位编辑名称或备注，左右方向键展开/收起文件夹；安装器支持简体中文与英文。权限、路径和验收边界见 [服务、无障碍与安装器](service-accessibility-installer.md)。

v0.8.0 为未签名预发布，仅手动安装，SHA-256 仅用于完整性校验，不代替签名。升级前先从托盘退出旧实例并备份数据。

v0.8.0 新增：新增 CLI 与崩溃恢复。先打开桌面程序，再通过同目录 `LaunchDesk.Cli.exe list`、`status --json`、`start "名称"`、`stop "名称"`、`restart "名称"` 控制现有实例；`start --all` / `stop --all` 管理全部项。名称重复时使用 `list` 中的 GUID，CLI 不启动第二个管理器、不绕过 UAC、不支持远程控制。已配置的按项提权仍需用户确认。退出码：0 成功、1 操作失败、2 参数错误、3 连接失败、4 超时；超时后请先查询状态。

异常退出后，下次启动可勾选恢复上次运行项或选择“不恢复”，均不会额外执行其他自启项。恢复使用当前配置，并通过启动前检查、依赖和就绪检测，不接管旧 PID。正常退出清除运行集合；运行记录保存在数据目录的 `session.json`，损坏时保留原件并阻止启动。细节见 [CLI 与崩溃恢复](cli-and-recovery.md)。

配置保存、读取、导出及手动备份统一 4 MiB 序列化字节上限，超限不修改已有文件。迁移失败时保留源数据、恢复所选目标空目录，并在错误信息中列出暂存目录；若权限阻止恢复空目录，会一并提示。独立临时文件及串行提交防止并发误删，但不自动合并不同编辑。

设置 → 外观 → 语言支持简体中文、English，保存后立即生效并保留选择。启动项名称、命令、路径和原始日志不翻译。

默认启动时在后台检查新版本，失败和已是最新版本不打扰，可在设置中关闭。发现新版本弹窗提供下载和发布页面入口；托盘状态下恢复窗口后再提示。下载必须由用户点击，不会静默安装。下载需通过 SHA-256、Windows Authenticode 及内置发行者证书固定验证；失败或取消时清理临时包，不替换旧程序和配置。当前尚未配置发行证书，应用内下载禁用，未签名安装包不会被接受。

隐私与联网说明：[隐私政策 / Privacy Policy](../PRIVACY.md)。

日志编码：新启动项默认 `auto`，每个输出通道优先 UTF-8，遇到无效 UTF-8 字节后切换到 Windows 系统 ANSI 编码。`system` 固定使用系统 ANSI 编码；中文旧版 PowerShell/BAT 可手动选 `gbk`，npm/Node 通常选 `utf-8`。已有配置不自动改动，修改编码后重新启动生效，历史日志不重新解码。自动识别不是绝对可靠，混合编码或恰好构成合法 UTF-8 的其他编码请手动指定；自动模式的标准输入使用 UTF-8。

首次使用没有示例启动项。应用会读取当前用户的已有配置，因此升级后仍保留原启动项和日志。

每个启动项可设置资源、参数、工作目录、环境变量和编码。npm 命令必须选择包含 package.json 的正确工作目录。文件夹是应用内分组，不移动实际文件；删除文件夹保留启动项。

启动项配置支持备注，显示在每行右侧运行按钮左边；较长备注省略显示，悬停查看完整内容，也可按备注搜索。双击备注（包括空白备注）原位编辑，Enter 或失去焦点保存，Esc 取消。列表不使用列头排序，避免文件夹与成员分离；调整顺序请使用拖拽或上下移动按钮。

“退出输入延迟（秒）”范围 0–300，默认 0。对于停止后需要确认的 npm/BAT 项，可勾选“退出输入前先发送 Ctrl+C”，配置退出输入 Y 和例如 2 秒延迟：先发送信号，等待后再输入。停止超时在输入发送后计时；若进程提前退出，不再发送。延迟是固定等待，不保证提示已出现，请按实际日志调整。未勾选时仍只发送退出输入，兼容使用 quit/exit 等命令的程序；未配置退出输入时仍发送 Ctrl+C。

编辑窗口的“启动前检查”验证路径、解释器及简单 npm 脚本配置，不执行命令。真正启动前也执行检查；检查失败时不会启动依赖项。复杂 cmd 表达式只做基础路径检查。

可拖拽未运行的启动项调整顺序或加入文件夹，拖到列表空白处移出分组。文件夹可排序，不支持嵌套。拖入 BAT/CMD、EXE、PS1、SH 文件会打开编辑窗口确认，不移动原文件，也不自动启动。

“服务就绪检测”默认关闭。启用 TCP、HTTP 或日志关键词检测后，状态先显示“等待就绪”，成功后显示运行中，再启动依赖项。超时为 1–300 秒，失败时停止该项。日志关键词区分大小写，只检查本次运行；HTTP 需返回 2xx，不跟随重定向。TCP/HTTP 可命中已有服务，不能证明端点属于新进程，也不是持续健康监控。

持续健康监控：编辑启动项可单独启用 TCP/HTTP 持续检查，复用 TCP/HTTP 就绪地址或配置独立地址。默认每次检查结束后等待 30 秒，单次超时 5 秒，连续失败 3 次标为不健康，连续成功 2 次恢复。状态列、悬停及底部状态栏显示健康、最近检查和原因。只在就绪后运行；停止时取消。

健康异常自动重启默认关闭；开启后只重启当前项，不连带处理依赖。默认冷却 60 秒，滚动 10 分钟最多 3 次，可调整；达到限制时保留进程并显示原因，持续失败且限制解除后可再重启。沿用退出输入和停止超时，用户停止后不会再次自启。此功能尚未包含在 v0.8.0 发布包中。请使用轻量、无副作用的健康接口；持续检查会访问目标地址。

窗口关闭会收起到托盘。托盘菜单的“退出”会停止受管进程。升级或卸载前请先退出旧实例。

双击名称可原位重命名，Enter 保存、Esc 取消，失去焦点保存；其他设置仍使用编辑按钮。启动项的“启动顺序”范围 0–9999，数字小的先启动，同值按列表顺序，依赖项优先于此顺序。此规则适用于全部启动、文件夹启动和登录自启，单独运行不自动启动其他无关项。

选中文件夹时显示组内各项的合并日志，按时间排列并注明来源。过滤、暂停、清空显示、导出和确认后删除历史均作用于整个文件夹。输入不会广播到文件夹内的进程，请选中具体启动项后发送输入。

日志中的 HTTP/HTTPS 链接高亮并带下划线，悬停显示地址，Ctrl+点击使用默认浏览器打开。普通点击不跳转，不自动访问链接；请只打开可信日志中的地址。

默认配置及日志目录为 %LOCALAPPDATA%\LaunchDesk。卸载不会删除这些用户数据。便携模式使用程序旁的 portable.flag 和 data 目录。

日志面板支持过滤、清空、导出及输入。清空显示不删除历史日志；删除历史需单独确认。

v0.6.0：日志按行虚拟化，只布局可见行；支持可见行内字符选择、按行选择和 Ctrl+A 全选/复制，复制可包含未渲染行。暂停后可更稳定地检查输出；不暂停时，保留行选择和阅读位置随历史窗口调整。长行可横向滚动。磁盘原始记录及导出不受虚拟化影响。单条超长输出仍有布局成本，不承诺实时帧率。

损坏的历史记录在查看及导出时跳过，导出结束显示跳过数量，原始文件不修改。导出先写临时文件，全部成功后替换目标；失败不截断已有导出文件。删除启动项释放运行时与写句柄，不删除历史日志。强杀使用 0xE04C4401，日志单独标明管理器终止；若根进程早已退出，仍保留它的真实退出码。

状态刷新异常会记录到当前数据目录的 diagnostics/errors.log，并在下一轮继续尝试；重复同类错误限频记录。加载或未捕获的界面异常会记录现场，停止受管进程后退出；未观察到的任务异常也会记录。诊断日志按约 2 MiB 轮换，保留 3 份旧文件；磁盘不可写时不能保证诊断落盘。

可靠性：损坏配置会从自动/手动备份中选择最近的有效副本恢复，保留损坏原件并提示来源，本次启动不执行自启。无有效备份或未来配置格式时不覆盖原件。历史日志启动时及每小时后台清理；被占用文件暂缓删除并记录内存诊断，不影响正常日志写入。真实写入失败仍会停止受管进程。导出使用各文件捕获时的长度，不包含之后追加的记录，不阻塞整个导出期间的日志写入。

若目标不读取标准输入，输入发送最多等待约 2 秒；超时后停止受管进程树，等待底层管道释放并报告错误。输入排队也有 2 秒上限；排队超时本身不会停止进程。

设置中的“数据与备份”显示当前实际目录，提供打开数据目录、打开备份目录及立即备份入口。手动备份在 backups\manual 中，不参与最近 20 份自动备份清理；只包含配置，不包含日志或脚本。恢复时使用主窗口配置导入，并先停止所有启动项。

可输入或选择新的空数据目录。切换前停止全部项；保存时复制配置、日志和备份，成功后立即切换并保留旧目录。便携模式使用程序旁的 data，不允许改为其他路径；要使用自定义目录，请取消便携模式。非空目录和符号链接不能作为迁移目标。用户模式的目录记录位于 %LOCALAPPDATA%\LaunchDesk-location.json，便携标记优先；卸载仍保留用户数据与目录记录。

项目及问题反馈：https://github.com/hailaij/LaunchDesk

设置中的“关于 LaunchDesk”提供版本、许可证和手动“检查更新”，可随时再次查询 GitHub 正式发布版本。新版本提示可以查看说明、打开发布页面；证书配置完成后可点击下载并验证安装包。不自动安装、退出应用或停止服务。
